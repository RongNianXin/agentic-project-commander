# Codex Workflows

这是一个面向 Codex Desktop 的个人工作流仓库，用于整理总指挥规则、故障排查经验、技巧性提示词和本地辅助工具。公开内容应可下载、可审查，不包含本机身份、真实任务 ID、凭据或私人提示词。

## 目录架构

| 目录 | 内容 |
| --- | --- |
| [第二代总指挥的工作模式](第二代总指挥的工作模式/) | 薄总指挥、Goal、专项任务、状态交接、授权门禁、模型策略和复盘规则。 |
| [故障排查与解决经验](故障排查与解决经验/) | 已复现并完成脱敏的 Codex / CC Switch 故障现象、原因、恢复步骤和辅助脚本。 |
| [其他 Codex 技巧性提示词](其他%20Codex%20技巧性提示词/) | 可直接复制或按实际需求修改的通用提示词。 |
| [实用小工具](实用小工具/) | 只读或可回滚的本地辅助工具及公开版说明。 |

根目录文件的职责：

- `AGENTS.md`：约束 AI 的访问、修改、验证和远端写入行为。
- `.gitignore`：阻止私人资料、生成报告、缓存和本地过程文件进入 Git。
- `CHANGELOG.md`：记录公开版本的重要变化。
- `LICENSE`：MIT 许可证。

`全局提示词（严禁AI自动修改）`、`其他资料`和文件名含“自用”的 DOCX 只保存在本地，不会同步到公开仓库。

## 总指挥工作流从哪里开始

操作者建议直接从 [01-操作者操作手册.md](第二代总指挥的工作模式/01-操作者操作手册.md) 开始。

日常使用时，操作者通常只需要关注 `01`：

1. 首次使用时，按手册登记本地规则目录。
2. 根据当前目标选择对应场景，复制提示词并填写必要信息。
3. 其余 `00`、`02`～`10` 由 AI 根据操作手册和规则注册表自动核对、按需读取，不要求操作者逐份阅读。

[00-第二代工作流总览.md](第二代总指挥的工作模式/00-第二代工作流总览.md) 是架构地图和规则注册表；需要理解整体设计、阅读顺序或排查规则冲突时再查看。正常交接可使用 [总指挥轻量交接启动配置.md](第二代总指挥的工作模式/总指挥轻量交接启动配置.md)。

规则仓库与真正要开发的目标项目应分开。只有维护这套规则本身时，才把本仓库作为 Codex 的目标项目。

## 隐私与公开边界

- `.gitignore` 负责阻止 Git 跟踪本地私人文件；它不是访问权限系统。
- `AGENTS.md` 进一步要求 AI 未经明确授权不得读取、修改或上传私人目录和自用文件。
- 高度敏感资料仍建议放在仓库和 Codex 工作区之外。
- 提交前应核对 `git status`、`git diff --cached`，并执行敏感信息扫描。

## 适用范围

- 当前主要面向 Windows、GitHub 与 Codex Desktop。
- 故障记录中的软件版本和第三方工具行为具有时间性，使用前应重新核对当前版本。
- 本项目是社区实验项目，与 OpenAI 不存在官方隶属或背书关系。
