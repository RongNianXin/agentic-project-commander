# Agentic Project Commander

Agentic Project Commander 是一个社区实验项目，用于抽象并公开一套通用的 AI 协作工作流：由“项目总指挥”管理目标与边界，由专项任务处理有限范围内的工作，通过事件路由同步状态，在关键节点设置人工门禁，并以可审计、可验证的方式安全交付。

本仓库只描述通用方法、模板与安全边界，不包含任何来源项目的业务、人员、组织、仓库或内部技术信息。

## 当前状态

- 项目仍处于最小初始化阶段，当前未公开发布。
- 目前仅在 Codex Desktop 中进行过实际尝试。
- 其他 Codex 形态及其他 AI 工具尚未验证，不应假定兼容性或效果一致。
- 本项目是社区实验项目，与 OpenAI 不存在官方隶属或背书关系。

## 核心构件

1. **项目总指挥**：维护目标、范围、事实基线、验收标准和最终决策。
2. **专项任务**：在明确边界内完成可独立验证的工作，不横向获取无关上下文。
3. **事件路由**：使用脱敏、结构化、可追踪的事件包传递规则和结果。
4. **人工门禁**：在远端写入、发布、权限、费用和不可逆操作前等待明确授权。
5. **安全交付**：在提交或公开动作前执行差异审查、隐私检查、Secret 检查和必要验证。

工作流概览见 [docs/WORKFLOW_OVERVIEW.md](docs/WORKFLOW_OVERVIEW.md)，公开信息边界见 [docs/SECURITY_BOUNDARY.md](docs/SECURITY_BOUNDARY.md)。

## 安全原则

- 示例只使用虚构占位符，例如 `OWNER/REPO`、`PR #123`、`Issue #456`、`<PROJECT_ROOT>` 和 `<COMMANDER_TASK_ID>`。
- 不提交真实身份、绝对路径、内部编号、凭据、私密链接或来源项目细节。
- 不因本地修改授权而推定远端写入、发布或部署授权。
- 每次提交与公开动作前，人工核对待提交文件和完整差异。
