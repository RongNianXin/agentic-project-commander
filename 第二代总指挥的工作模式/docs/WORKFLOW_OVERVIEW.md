# 工作流概览

本页只提供导航，不单独维护另一套规则摘要。本分类目录中的 `00`～`10` 是第二代工作流的唯一正式规则来源；如本页与编号文档不一致，以编号文档为准。

## 从哪里开始

1. 使用者先打开 [01-操作者操作手册.md](../01-操作者操作手册.md)，按“下载后 3 步启动”登记本地规则目录。
2. AI 从 [00-第二代工作流总览.md](../00-第二代工作流总览.md) 读取注册表、版本和按需加载顺序。
3. 首次启动或恢复总指挥时，按 `01` 的“场景 1”读取 `02`、`09`、`10`，先只读重建事实基线。
4. 需要先在本地连续实现和人工验收时，使用 `01` 的“场景 2B”；AI 会自动判断新目标、远端续作、混合或恢复场景，并在真正发布前单独生成远端执行卡。
5. 正常交接候选阶段可按 [总指挥轻量交接启动配置.md](../总指挥轻量交接启动配置.md) 执行精简核验；配置或来源指纹异常时回退到对应正式规则。

## 辅助工具

- [本地会话检查工具](../../实用小工具/查看当前任务本地对话的文件大小/README.md)：只读检查本地会话文件容量、自动压缩次数和最近输入占窗口比例，辅助判断是否准备交接。
